Payroll, end to end.

A complete desktop payroll system on a MySQL database: login and authentication, employee records, automated gross / deduction / net-pay calculation, and printable payslips through Crystal Reports.

01The problem

Small organizations still run payroll on spreadsheets, error-prone, hard to audit, and impossible to hand a clean payslip from. I built a self-contained desktop system that stores employees in a real relational database, calculates pay consistently, and prints a proper payslip every time.

02The system
03What I built

Authentication + employee records

A login gate guards the app, and an employee module does full create / read / update / delete over MySQL, the system of record for everyone on payroll.

One trusted source for employee data

A consistent pay calculation

The payroll module computes gross pay, deductions, and net pay the same way every run, so the numbers are reproducible and auditable instead of hand-typed.

Pay that's calculated, not guessed

Printable payslips with Crystal Reports

Integrated Crystal Reports to turn the computed payroll into a formatted, printable payslip, the document an employee actually receives.

A real artifact at the end of the workflow
04What it shows

A complete, shipped application across the whole stack: the UI, a relational data model, financial calculations that have to be right, and document generation. I designed it from an ER diagram first, then built it out module by module.
