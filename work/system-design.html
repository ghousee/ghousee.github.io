Two designs recreated from coursework: a normalized relational schema and an object-oriented domain model. For the production data architecture I built at Apex, see the Apex case study.

01Relational ERD, Student Housing Platform

A 13-table schema (DAMG 6210) for a campus housing marketplace: a supertype/subtype model for users, a many-to-many junction for amenities, and a clean listing → application → lease → payment flow. Simplified here for clarity.
